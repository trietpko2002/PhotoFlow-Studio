# 🚀 PhotoFlow Studio 6.0 có gì đặc biệt?

PhotoFlow Studio bắt đầu từ một công cụ lọc ảnh đơn giản với chức năng **Preview / Cut / Copy**.

Qua nhiều phiên bản, project đã phát triển thành một bộ công cụ desktop hoàn chỉnh hơn cho workflow ảnh và video:

- Duyệt, chọn và phân loại ảnh/video.
- Làm việc với tối đa **10 thư mục đích**.
- Chọn nhiều file bằng Ctrl / Shift.
- Gắn nhãn, chấm sao và lọc dữ liệu.
- Đổi tên từng file hoặc đổi tên hàng loạt.
- Studio Live theo dõi ảnh mới được truyền vào máy.
- Workflow ảnh thẻ sinh viên.
- Cắt ảnh 2×3 / 3×4 / 4×6.
- Ghép ảnh lên giấy 10×15 cm.
- Chỉnh sáng / tương phản.
- So sánh ảnh.
- Tìm file trùng nội dung bằng SHA-256.
- Xuất CSV.
- Sao chép / di chuyển có kiểm tra dữ liệu.
- Hoàn tác thao tác file gần nhất.
- Giao diện sáng / tối.
- Hoạt động offline sau khi cài đặt.

> **6.0 là cột mốc gom toàn bộ workflow chính của PhotoFlow Studio vào một trải nghiệm thống nhất, rõ ràng và an toàn hơn.**

## ✅ 2. Chọn và phân loại file nhanh

PhotoFlow Studio hỗ trợ workflow chọn ảnh giống các ứng dụng quản lý ảnh chuyên dụng:

| Thao tác | Chức năng |
|---|---|
| `P` | Chọn ảnh |
| `X` | Đánh dấu loại |
| `U` | Bỏ nhãn |
| `0–5` | Chấm sao |
| `Ctrl + Click` | Chọn nhiều file rời |
| `Shift + Click` | Chọn một dải file |
| `Ctrl + Z` | Hoàn tác thao tác file gần nhất |
| `F2` | Đổi tên |

> `X` chỉ gắn nhãn, **không xóa file**.

## 📁 3. Tối đa 10 thư mục đích

Không còn bị giới hạn trong workflow chỉ có một thư mục nguồn và một thư mục lọc.

Bạn có thể:

- Tạo tối đa **10 thư mục đích**.
- Đặt tên riêng cho từng thư mục.
- Chỉnh sửa đường dẫn thư mục.
- Chọn nhanh thư mục đích từ giao diện.
- Sao chép hoặc di chuyển ảnh/video vào từng nhóm riêng.

Ví dụ:

```text
01_Da_Chon
02_Loai
03_Khach_A
04_Khach_B
05_In_Anh
06_Chinh_Sua
07_RAW
08_JPEG
09_Video
10_Backup
```

## 📡 4. Studio Live — nhận ảnh mới theo thời gian thực

Studio Live được thiết kế cho workflow chụp ảnh tại studio, sự kiện hoặc làm ảnh thẻ.

Cách hoạt động:

1. Máy ảnh hoặc phần mềm của hãng truyền ảnh vào một thư mục trên Windows.
2. PhotoFlow Studio mở thư mục đó.
3. Bật **Studio Live**.
4. Bật **Theo ảnh mới nhất**.
5. Ảnh mới xuất hiện sẽ được app phát hiện sau khi file ổn định.

Ứng dụng:

- Chụp ảnh thẻ.
- Chụp sinh viên.
- Chụp sự kiện.
- Chụp studio.
- Workflow tethering thông qua thư mục nhận ảnh.

> PhotoFlow Studio theo dõi **thư mục nhận ảnh**, không trực tiếp điều khiển nút chụp hoặc Live View của máy ảnh.

### Cơ chế kiểm tra file

- Quét ảnh mới theo chu kỳ ngắn.
- Chờ dung lượng và thời gian sửa đổi ổn định.
- JPEG có thêm kiểm tra dấu kết thúc file.
- Có thể tăng thời gian chờ khi dùng ổ mạng hoặc đường truyền chậm.
- Khi thư mục mất kết nối, app giữ danh sách cũ và thử kết nối lại.

## 🎓 5. Workflow ảnh thẻ sinh viên

Một trong những workflow lớn nhất của PhotoFlow Studio.

Có thể nhập:

- Mã sinh viên.
- Họ tên.
- Số thứ tự tiếp theo.

Ví dụ tên file:

```text
SV001_Nguyen_Van_An_0007.jpg
```

Hỗ trợ:

- Đổi tên ảnh đã chọn.
- Đổi tên hàng loạt.
- Tự đổi tên ảnh mới đi vào thư mục.
- Không ghi đè nếu tên đã tồn tại.
- Chỉ tăng số khi thao tác file thành công.
- RAW và JPEG có thể có bộ đếm riêng.

> Tự đổi tên ảnh mới được tắt khi khởi động lại nhằm giảm nguy cơ dùng nhầm thông tin của người trước.

## ✂️ 6. Cắt & chỉnh ảnh

Các công cụ chỉnh sửa cơ bản được tích hợp ngay trong app:

- Điều chỉnh sáng.
- Điều chỉnh tương phản.
- Cắt ảnh theo tỷ lệ.
- Điều chỉnh vị trí khung cắt ngang / dọc.
- Xem trước bản xuất trước khi lưu.

### Ảnh thẻ hỗ trợ

- 2 × 3 cm.
- 3 × 4 cm.
- 4 × 6 cm.

### Ghép ảnh

Có thể ghép nhiều ảnh thẻ lên tờ:

```text
10 × 15 cm
```

Kích thước pixel được tính theo **300 PPI**.

> Khi in, cần chọn đúng kích thước vật lý thay vì dùng tùy chọn Fit-to-page.

## 🔍 7. So sánh ảnh

Chọn 2 ảnh bằng `Ctrl + Click`, sau đó sử dụng chức năng **So sánh** để kiểm tra nhanh hai file.

Phù hợp khi cần:

- Chọn ảnh nét hơn.
- So sánh biểu cảm.
- Kiểm tra ảnh gần giống nhau.
- Quyết định ảnh nào giữ lại.

---

## 🧬 8. Tìm file trùng nội dung bằng SHA-256

PhotoFlow Studio có thể kiểm tra file trùng dựa trên **SHA-256**.

Điều này giúp tìm file có nội dung giống nhau ngay cả khi tên file khác nhau.

> Đây là kiểm tra trùng nội dung, không phải AI nhận diện ảnh gần giống.

App **không tự động xóa file trùng**.

---

## 📝 9. Đổi tên mạnh hơn

### Đổi tên một file

Nhấn:

```text
F2
```

Sau đó nhập tên mới không gồm phần mở rộng.

### Đổi tên hàng loạt

Có thể nhập:

- Tiền tố.
- Số bắt đầu.

Ví dụ:

```text
Khach_0001.jpg
Khach_0002.jpg
Khach_0003.jpg
```

Nếu tên file đã tồn tại:

- File đó được bỏ qua.
- App báo lỗi.
- Không tự ghi đè.

---

## 💾 10. Sao chép / Di chuyển an toàn hơn

PhotoFlow Studio không chỉ gọi lệnh move đơn giản.

Quy trình di chuyển sử dụng:

```text
COPY → VERIFY → DELETE
```

Ứng dụng kiểm tra:

- SHA-256.
- Kích thước file.
- Thời gian sửa đổi.
- Trạng thái ghi dữ liệu ở đích.

Chỉ khi bước kiểm tra hoàn tất, file nguồn mới được xóa.

### Lưu ý

- Không rút thẻ nhớ khi app đang xử lý.
- Di chuyển kiểu copy–verify–delete có thể chậm hơn rename thông thường.
- Cần đủ dung lượng trống ở ổ đích.
- Với dữ liệu quan trọng vẫn nên có backup.

---

## ↩️ 11. Hoàn tác thao tác file

`Ctrl + Z` có thể phục hồi **một file gần nhất** trong phiên đang mở.

Trước khi hoàn tác, app kiểm tra hash để hạn chế việc khôi phục sai nếu:

- File đã bị chỉnh sửa.
- Đường dẫn cũ đã bị file khác chiếm.

> Hoàn tác hiện tại không phải transaction history qua nhiều lần khởi động.

---

## 📊 12. Xuất CSV

Có thể xuất danh sách UTF-8 gồm:

- Tên file.

- Loại file.
- Kích thước.
- Nhãn.
- Số sao.

Phù hợp cho:

- Quản lý danh sách ảnh.
- Bàn giao dữ liệu.
- Kiểm kê file.
- Import sang workflow khác.

## 🌙 13. Light Mode / Dark Mode

PhotoFlow Studio hỗ trợ:

- Giao diện sáng.
- Giao diện tối.
- Cấu hình được lưu lâu dài.

Mục tiêu của giao diện mới:

- Ít rối mắt.
- Dễ thao tác.
- Dễ nhìn đường dẫn nguồn / đích.
- Phù hợp khi làm việc nhiều giờ.

# 🎞️ Định dạng hỗ trợ

## Ảnh

Các định dạng phổ biến được hỗ trợ trong workflow xem / xử lý tùy decoder của Electron và Windows.

## RAW

PhotoFlow Studio có thể phân loại, đổi tên và chuyển các file RAW như:

```text
CR2
CR3
NEF
ARW
DNG
RAF
ORF
RW2
```

Hiện tại app **chưa tích hợp bộ giải mã RAW chuyên dụng**.

RAW + JPEG được xem như các file riêng biệt và chưa tự liên kết thành một cặp.

## Video

Một số định dạng như:

```text
MOV
MKV
AVI
MTS
```

phụ thuộc codec của Electron / hệ điều hành.

PhotoFlow Studio không tích hợp FFmpeg để chuyển mã video.

# ✅ Check file trước khi sử dụng

Khi phát hành bản 6.0, nên công bố checksum của **đúng file release chính thức**:

```text
SHA-256: <UPDATE_AFTER_BUILD>
```

Có thể kiểm tra bằng PowerShell:

```powershell
Get-FileHash ".\PhotoFlow-Studio.exe" -Algorithm SHA256
```

Hoặc với file ZIP:

```powershell
Get-FileHash ".\PhotoFlow-Studio-6.0-Windows-x64.zip" -Algorithm SHA256
```

> Không nên dùng checksum của phiên bản cũ cho bản 6.0.
